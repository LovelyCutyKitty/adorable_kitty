# Dow innovation 제품 재고관리

아버님 개인용 재고관리 웹앱입니다. 갤럭시 크롬에서 접속한 뒤 `Chrome 메뉴 → 홈 화면에 추가`를 선택하면 앱처럼 쓸 수 있습니다.

## 사용 순서

1. **제품 재고**에서 제품명·규격·현재 재고를 처음 한 번 등록합니다.
2. **발주**에서 카톡 메시지 한 건을 붙여넣고 `내용 읽어오기`를 누릅니다.
3. 자동으로 나온 품목·규격·수량을 확인하고, 발주일과 납기일을 달력으로 입력한 뒤 저장합니다.
4. 생산이 끝나면 **제품 재고 → 생산 완료 입력**으로 수량을 더합니다.
5. 발주 상세에서 **출고 완료**를 누르면 해당 수량이 재고에서 차감됩니다.

## 중요한 점

- 데이터는 이 앱을 사용한 브라우저 안에 저장됩니다.
- 휴대폰 교체·초기화 전에는 우측 상단 메뉴에서 반드시 **데이터 백업하기**를 누르세요.
- 카톡 메시지는 자동으로 읽지만, 저장 전 품목·규격·수량을 꼭 확인하세요.

## GitHub Pages 배포

1. GitHub에서 `dow_beam` 이름의 새 저장소를 만듭니다.
2. 이 폴더 안의 파일 전체를 저장소 최상단에 올립니다.
3. 저장소의 **Settings → Pages → Deploy from a branch → main / root**를 선택합니다.
4. 배포 주소는 `https://lovelycutykitty.github.io/dow_beam/` 입니다.
