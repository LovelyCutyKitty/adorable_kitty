# 말따먹기 모바일 웹앱

엑셀 원본을 브라우저용 문제 데이터로 바꾼 정적 웹앱입니다.

## 포함 기능

- 전체 랜덤 12문제
- 회차별 풀이와 회차 종료 후 일괄 채점
- 오답 복습
- 빈도 2회 이상 문제의 이어풀기
- 오답·암기·빈출 진도: 휴대폰 브라우저에 저장

## 데이터 업데이트

원본 엑셀 파일을 교체한 뒤 아래를 실행합니다.

```bash
python3 convert_xlsx.py
```

생성된 `data/questions.json`을 포함해 웹 호스팅에 올리면 됩니다.

## 주의

이 버전의 기록은 로그인/서버가 아니라 각 기기 브라우저에 따로 저장됩니다. 같은 진도를 PC와 휴대폰에서 공유하는 기능은 다음 단계에서 추가할 수 있습니다.
